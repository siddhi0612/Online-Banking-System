ATM Simulator System
📌 Project Overview
This ATM Simulator System is a Java-based application that replicates the core functionalities of a real-world Automated Teller Machine (ATM).
Designed as a console or GUI-based system, it enables users to perform essential banking operations securely and efficiently.

🎯 Features
💵 Deposit Funds – Add money to your account securely.

🏧 Withdraw Cash – Withdraw available funds with balance checks.

🏦 Open New Bank Account – Create a new account with required details.

📄 Mini Statement – View recent transactions in a concise statement format.

🔐 Change PIN – Update your ATM PIN securely.

➕ Additional Features – More banking utilities can be extended easily.

🛠️ Technologies Used
Programming Language: Java

Database: MySQL

IDE/Tools: IntelliJ IDEA , MySQL Workbench
